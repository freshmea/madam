
## Education 목록 분류

프로젝트·온라인교육·오프라인교육은 projects.html의 같은 카드 목록에서 전환한다. date는 소개한 강의/프로젝트 종료 연월(YYYY-MM), 내림차순. 고려대 IoT 강사 담당 종료는 6월이며 전체 과정 7월과 구분한다. 실제 월이 미확인된 예시 3개는 draft로 보존하고 공개 목록에서 제외한다.
